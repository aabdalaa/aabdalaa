### 🧠 Sobre Mim

Sou um desenvolvedor apaixonado por **arquitetura de software, automação e experiência do usuário**. Atuo na criação de soluções completas — desde aplicações desktop corporativas com instaladores nativos para Windows até bots automatizados, microsserviços e infraestrutura como código (IaC).

- 🏢 **Desenvolvedor do ecossistema ENTROPY:** Softwares pensados para ir além do escopo interno, combinando robustez técnica, minimalismo e interfaces limpas inspiradas no Fluent Design.
- 🧱 **Engenharia & Qualidade:** Foco absoluto em segurança, código desacoplado, documentação exaustiva e governança de dados.
- 🤖 **IA & Automação:** Desenvolvimento de assistentes com processamento de voz, rotinas inteligentes de background e integrações multi-plataforma.
